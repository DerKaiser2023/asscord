# Ragecord

A Xi approved Discord bridge for Minecraft 1.7.10 using Forge.

With Xenofactions installed, Minecraft chat relay requires its 1.7.10 finalized public chat API. Discord receives only server-approved public message bodies, after Xenofactions moderation and filtering. Faction/alliance chat, private messages and command input are excluded. Older Xenofactions builds without this API disable Minecraft chat relay and log an update requirement; other Discord features remain available. Without Xenofactions, ordinary uncanceled Forge chat is relayed from the final chat component.
